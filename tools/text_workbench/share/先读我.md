# 汉化校对工作台 · 离线分享版

**双击“汉化校对工作台.html”就能使用。** 不需要安装软件、运行服务器、联网、提供ROM或字体。可以把HTML直接发给别人，也可以发送整个ZIP。

底稿：初代热血硬派优化版汉化 v2.0-rc2；与不掉血hack版文字相同。含1088条文本（包括75个优化扩展表条目）和453个共享人物名词条，共1541条对照。存读档、命名键盘和标题不在校对范围内。

## 怎么改

1. 左边搜索原文、译文或编号，也可以选择“优化版新增”“道具”“地名”等分类。
2. 中间并排看日文原文和当前中文，在“你的修订”里输入修改。
3. 灰色的姓名、数值、换行等标记由游戏使用，工作台会自动保留。姓名词条最多两个字，其他文本的段内回车会转成空格。
4. 有疑问可写备注并标记“待确认”，确认后标记“已校对”。“已修订”筛选只看改过的条目。
5. 随时点击右上角“导出修订稿”，得到JSON文件。把它发回，或给其他人导入继续校对。

**只发送原HTML不会带上你的修改。** 修订自动暂存在当前浏览器，HTML本身没有被改写。分享改过的内容时，请同时发送导出的修订稿。换电脑、浏览器、文件位置、清理浏览器数据前先导出；若暂存失败界面会提示。

别人收到：双击同一份HTML，点击“导入修订稿”，选择JSON。不同底稿版本不会混入；与本机记录冲突时会提示确认。没出现在导入文件里的本机记录会保留。

“导出对照表”得到CSV，方便用表格软件阅读和讨论；回传修订请使用JSON。人物名是共享读音词条，改动会影响所有使用该读音的记录。

快捷键：Ctrl+S导出修订稿，Ctrl+Enter标记已校对，Alt+左右键切换条目。

## 交给维护者

catalog.json和check_revisions.py用于独立校验别人发回的修订，校对者不需要运行Python：

    python check_revisions.py "修订稿.json" --catalog "catalog.json" --output "待合入修订.json"

这一步验证底稿、条目身份、游戏标记和姓名长度，生成修订提案，不改ROM。正式合入工程后还需重建字库和验证游戏显示。
