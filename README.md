## 离线原文／译文校对

[下载校对工作台HTML](tools/text_workbench/share-rc3/汉化校对工作台.html)（打开该文件后点GitHub的 **Download raw file / 下载原始文件**），保存后双击即可离线使用，无需安装或运行服务器。[使用说明](tools/text_workbench/share-rc3/先读我.md)。

工作台含 **1088条文本＋453个共享人物名词条**：原文与当前译文并排、输入修订、搜索分类、备注、已校对／待确认、JSON修订稿导入导出、CSV对照表。修改自动暂存于浏览器；**发回修改必须导出JSON，原HTML不会自动带上修订**。修订不会直接改ROM，合入后仍需重建字库和验证显示。[源码与维护方法](tools/text_workbench/README.md)。

代码及DOM模型／导入导出检查通过；真实浏览器视觉、file协议与下载对话框尚未验收。未把模型测试称为浏览器测试。

## 优化版这次做了什么

从原优化版直接重新汉化，复用审校译文与已知接口，重新接入真实消息、菜单、状态和战斗HUD路径。

- 694个原主表入口＋75个优化扩展入口，连同道具、技能、地名和提示合计1088条；优化新增／修改台词已纳入。
- 正文字形按3条滚动行和13列位置分配，保留原连续消息链，避免多人姓名与正文互相覆盖。
- 六项菜单保留优化版“互伤”开关；状态页姓名、状态词、装备名称分别适配。
- **战斗HUD：国夫保留原版「くにお」，力和敌牌使用完整16×16。** 两块敌牌各有独立字形槽，队列忙时保留更新并重试。
- 514条人物记录仅改姓名，保留后12字节及表后玩法参数。NPC保留，剧情等待原战斗结算。
- 不掉血版是可选变体：两主角不扣HP，敌人仍正常受伤；不自动合入正常版。
