# 初代热血硬派（SFC）简体中文汉化

本仓库包含《初代熱血硬派くにおくん》的 **IPS 补丁、汉化源码、回归测试与逆向记录**。不提供游戏 ROM、字体、模拟器或玩家存档。

> **当前版本：v39-rc8 · 阶段性修复测试版**
> 仓库更新日期：**2026-10-05**。根目录 `kuniokun_cn.ips`、源码和三份生成侧车已同步到 rc8。
> 正确应用补丁后的 ROM CRC32：**`BD76DCA1`**。不是全界面汉化、自然全流程通关或实体机验收版。
> 版本指纹及边界见 [当前状态](notes/current-state.md)；此次同步见 [发布记录](notes/发布记录_GPT_20261005_rc8.md)。

## 这版包含什么

- **译文审校**：对照日文审校已识别的 1013 项文本，实际修改 195 项；修正不通顺句、术语及部分地名，不靠删译意凑字库。
- **片尾显示与场景**：完整罗马字署名；片尾独立节拍及缩进；限定清除残留列车阶段，修复柱子漂移和额外音效请求。
- **状态页长道具名**：扩大实际字形槽分配，避免尾字覆盖前字。
- **停车场剧情交接**：同步三人战后的结算和剧情移动，保留同行 NPC、原台词与原开门流程。
- **梅田列车**：修正文字队列字节游标与相邻列车位移的混用，避免文本上传等待／写入影响列车。
- **文字与菜单**：保留完整消息道具名字形、地名修订、字框下缘残留修正，以及战斗 HUD、非空道具／气力列表和底边漂移修复。

详细变更见 [rc8](notes/修复记录_GPT_v39-rc8_片尾与全量审校.md)、[rc7](notes/修复记录_GPT_v39-rc7_停车场剧情交接.md)、[rc6](notes/修复记录_GPT_v39-rc6_文本显示.md)、[rc5](notes/修复记录_GPT_v39-rc5_梅田剧情验收.md) 和 [rc4](notes/修复记录_GPT_v39-rc4.md)。

## 交付原则

1. IPS 只打在**无外部头、CRC32 `56C05339` 的干净日版原 ROM**上，不叠到旧汉化 ROM。
2. 使用新 ROM 时冷启动，不加载旧版即时存档；先备份普通 SRAM，不自动删除。
3. 源码、补丁及三份侧车必须匹配。维护机已有的根目录 ROM 可能仍是旧版；核对指纹，不以文件名认版本。
4. 构建在独立副本进行；不覆盖原版、玩家唯一存档或最近可用交付。
5. 不上传 ROM、字体、模拟器、状态、内存转储或玩家截图／视频。
6. 仓库未统一声明全部代码、译文和素材的开源许可证，不擅自替上游授权。
