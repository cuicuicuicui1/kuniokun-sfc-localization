# 初代热血硬派（SFC）简体中文汉化

本仓库包含《初代熱血硬派くにおくん》的 **IPS 补丁、汉化源码、回归测试与逆向记录**。不提供游戏 ROM、字体、模拟器或玩家存档。

> **当前版本：v39-rc4 · 阶段性修复测试版**
> ROM CRC32：`48B37673`；并非全汉化、全流程通关或主机硬件验收版。
> 文档整理日期：**2026-10-02**；这次整理不改变 ROM 或 IPS。

## 这版修了什么

- **战斗 HUD 敌人名字**：上下半字颠倒、私有字形被覆盖、队列预留与繁忙重试。
- **气力招式列表**：中文名称通过真实列表绘制路径上传，不与静态菜单标签混为一谈。
- **消息中的道具名称**：修正 `$DE` 分支、字形复制宽度与隐藏 B 索引。
- **非空道具列表**：16×16 字体、上传队列回收、连续滚动时的字形占用。
- 保留 rc3 的**文本框底边漂移修复**：打字倒计时使用 `$03E7`，不占用 HDMA 表的 `$03C4`。

2026-10-01 的 rc4 记录：**20 PASS + 1 INFO、零失败**；ROM/IPS 确定性重建与 IPS 重放一致。无头 Mesen 验证自然开局至大厅战斗，以及受控非空菜单/消息；同 ROM 另由 Snes9x 核心复核。

**验证有边界**：非空菜单使用诊断夹具，不是自然取得物品的证据；未复现用户车库截图、未完成全流程通关。主角 HUD 假名、存档/命名界面、部分状态页仍有日文或待改字体。详见 [rc4 修复记录](notes/修复记录_GPT_v39-rc4.md)。

## 交付原则

1. IPS 打在**无外部头的日版原 ROM 副本**上，不叠到旧汉化 ROM 上。
2. 使用新 ROM 时冷启动；不要加载旧版本即时存档。普通 SRAM 先备份，不必因更新补丁自动删除。
3. 构建使用独立工作副本；原版、玩家存档与最近可用版本保持不变。
4. 代码、文本、补丁与文档可以按项目授权范围提交；不上传 ROM、字体、模拟器、SRAM、即时存档或诊断转储。

这是非商业的汉化研究工程，与游戏权利人无关。仓库未统一声明开源许可证；不要自行假定代码、译文、字体或游戏素材具有相同的再分发许可。
